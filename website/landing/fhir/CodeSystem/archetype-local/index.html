The archetype-local code systems

https://ferrobridge.eu/fhir/CodeSystem/archetype-local/ is the base of a family of code systems, one per openEHR archetype. The system of an archetype's local codes is this base followed by the archetype id, such as https://ferrobridge.eu/fhir/CodeSystem/archetype-local/openEHR-EHR-EVALUATION.problem_diagnosis.v1. The codes are the archetype's own at-codes, and their meaning is the term the archetype or the operational template defines for each.

No openEHR, HL7 or FHIRconnect text defines a URI for an archetype's local codes, so this family is FerroBRIDGE's own. An archetype id names a single archetype, and two versions of one archetype are two distinct archetypes (openEHR BASE, Base Types, Archetype Identifiers), so the at0003 of two archetypes are two concepts under two systems.

The interoperability component, the eehrxf crate, writes these systems when it turns an openEHR text item into FHIR codings. The interoperability component's page describes it.
