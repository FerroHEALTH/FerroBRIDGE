- The facade is the IHE MHD 4.2.3 Document Responder behind `[facade.mhd]`, which needs `[facade.identifier_search]`: Find Document References [ITI-67] answers one `DocumentReference` per document a Composition context assembles, the draft EEHRxF Annex III description of `Composition/[id]/$document` under the Composition's id; Find Document Lists [ITI-66] answers one SubmissionSet `List` per CONTRIBUTION that committed a document; Retrieve Document [ITI-68] reads the `$document` URL. Every parameter the Responder SHALL process is matched against the element the description fills, an unsupported parameter is ignored and named in the searchset unless `Prefer: handling=strict` asks for a `400`, both searches take `GET` and `POST`, and every answer is FHIR JSON or, when asked, FHIR XML. The `CapabilityStatement` instantiates `IHE.MHD.DocumentResponder`, and `Endpoint/mhd` names the Responder with the payload type `urn:ihe:iti:xds:2017:mimeTypeSufficient` in both FHIR formats.
