- The bridge can cache the pseudonyms the identity source answers over ITI-83. The new `[identity_source.cache]` table turns it on. The cache serves only while the deployment's PMIR subscription to the identity source's feed is active. Each ITI-93 message received at `POST /pmir/feed` forgets, on every replica, the identifiers of the patients it merged, updated or deleted. The receiver admits only the access tokens of the clients `feed_clients` lists, so the cache needs `[auth]` and `[state]`.
