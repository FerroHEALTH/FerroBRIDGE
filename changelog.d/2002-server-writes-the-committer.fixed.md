- A facade write no longer fails with `500` against a CDR that writes the committer itself. A single write states the change type and `system_id` in `openehr-audit-details` and no committer, which ITS-REST 1.1.0 leaves optional, and a transaction's CONTRIBUTION names the party the CDR authenticated: the bridge's client id under its client credentials grant, or the placeholder of an exchanged token's `iss` and `sub` or of a Basic user under the new `[cdr] committer_issuer`. The authenticated facade caller is no longer stated as the committer; the access record names it.
