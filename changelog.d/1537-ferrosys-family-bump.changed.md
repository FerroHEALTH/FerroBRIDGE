- The server and the operator console run on `ferrohealth-config` 0.2.8, `ferrohealth-server` 0.4.3 and `ferrohealth-telemetry` 0.2.4. A configuration refusal no longer echoes a value written unquoted, such as a secret set as a number, and a refusal inside an array of tables names its key with the element's index. The panic line of the log carries the server's request id of the request that panicked. The request span is named `{method} {route}`.
