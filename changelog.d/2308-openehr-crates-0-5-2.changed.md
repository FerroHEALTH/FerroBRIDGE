- The bridge now takes the `openehr-*` crates at 0.5.2, which no longer turn on `serde_json`'s `preserve_order` feature. The server, the console and the libraries are built with `serde_json`'s sorted map again, instead of an `IndexMap` with a randomly seeded hasher. `openehr-mapping-core` 0.9.3, `fhirconnect` 0.15.1 and `ferrobridge-hl7v2` 0.39.1 require it. Test builds still turn the feature on through the browser-journey driver (`thirtyfour`), which always enables it.
