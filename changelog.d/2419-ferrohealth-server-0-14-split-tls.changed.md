- The bridge moves to `ferrohealth-server` 0.14, `ferrohealth-config` 0.5, `ferrohealth-telemetry` 0.6, `ferrohealth-usage-report` 0.6, `ferrohealth-smart` 0.38 and `ferrohealth-session` 0.35, which verify every outbound TLS connection by its root. A chain to a root of `trust_roots_file` is verified by webpki on every operating system, ML-DSA certificates included, and a connection opens only once a revocation check cleared it: the check runs at the start and every 4 minutes, and it fails closed when no CRL or OCSP source answers. A chain to a root of the new `trust_roots_without_revocation_file` is trusted with no revocation check, for a private PKI that publishes no revocation service, and the start names those roots. Any other chain goes to the platform's verifier. A table that names a test or private CA in `trust_roots_file` with no CRL or OCSP responder now refuses the connection; name it in `trust_roots_without_revocation_file`.
