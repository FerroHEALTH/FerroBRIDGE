- `ferrobridge-validator` holds a dependency of another FHIR release, such as the FHIR 5.0.0 `xtehr.eu.ehds.models` that HL7 Europe Hospital Discharge Report 1.0.0 depends on, instead of refusing the package set: the package satisfies the dependency, its resources are never read, its own dependencies are not required, and a canonical only it defines is refused with the new `ResolveError::OtherRelease`. `Package::fhir_versions`, `PackageSet::other_releases` and the `Release::FHIR_VERSION` and `Release::CORE_PACKAGE` constants are new. `ResolveError` gains a variant, so a consumer that matches it exhaustively adds an arm. HDR 1.0.0, `hl7.terminology.r4` 7.4.0 and `xtehr.eu.ehds.models` 1.0.0 join the profile package pins, and a received discharge report validates through `ReceivedDocument::validate`.
