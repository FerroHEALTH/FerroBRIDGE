- The operator console runs on `ferrohealth-session` 0.2.2. `[oidc] resolve` reaches the provider's host at a fixed address, and `[oidc.tls]` names the client certificate the console presents to its provider (RFC 8705 §2) and the lowest TLS version of that connection. `POST /logout` goes to the provider's end-session endpoint only when the ended session holds an ID Token, so a Basic sign-out returns to the console's signed-out page.
