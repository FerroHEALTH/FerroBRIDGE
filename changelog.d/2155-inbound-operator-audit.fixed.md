- The inbound operator writes (`POST /operator/sources/{id}/settle`, `…/replay`, `…/reconcile` and `…/redeliver`) each log one operator audit line under the `ferrobridge::audit` target, naming the subject, the action (`retry`, `discard`, `replay`, `reconcile` or `redeliver`), the source id and the status, as every other operator write does. The line carries no value of the event and no reason.
