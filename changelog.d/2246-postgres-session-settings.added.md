- `[state]` and `[cdm]` take `statement_timeout`, `lock_timeout`, `idle_in_transaction_session_timeout`, `statement_cache_capacity`, `max_lifetime` and `idle_timeout`. Both PostgreSQL clients start every session with the three timeouts in the startup `options` parameter, read them back from `pg_settings` once connected, and refuse a server that does not hold them. The state store defaults to 30 s, 5 s and 60 s; the CDM sets no statement timeout, 60 s for a lock and 10 minutes idle in a transaction. Upgrade note: a connection URL that carries `options` is refused; set the timeouts in the section instead.
