                         ANNEX I – GENERAL CONVENTIONS FOR DATA MODELS


        1. Structure of the data models
     The data model tables in Annexes III to X contain the following columns:

        a) level - indicates the hierarchical level of the element within the data model;
        b) element name - identifies the data field or data group;
        c) element description - describes the information represented by the element;
        d) data type - specifies the data type used to represent the element;
        e) cardinality - specifies the minimum and maximum number of occurrences of the
           element;
        f) binding requirements - identifies the coding systems or value sets applicable to the
           element, where specified.

        2. Hierarchical levels

     The hierarchical structure of the data model is indicated using the symbol ‘+’. Each additional
     ‘+’ indicates a further level of nesting within the preceding data group. Elements without this
     symbol are at the highest level of the data model.

        3. Cardinality

     Cardinality specifies the minimum and maximum number of times an element may occur
     within the containing data model or data element. It is expressed as follows:

        a) ‘0..1’ (optional): the data element may be omitted or appear once;
        b) ‘1..1’ (mandatory): the data element shall appear exactly once;
        c) ‘0..*’ (optional and repeatable): the data element may be omitted or appear once or
           multiple times;
        d) ‘1..*’ (mandatory and repeatable): the data element shall appear at least once and may
           appear multiple times.

        4. Alternative data types

     The notation ‘[x]’ indicates that the element may be represented by one of the alternative data
     types specified for that element. The selected alternative inherits the cardinality of the
     containing element.

        5. Definitions of data types

     The following data types are used in Annexes III to X.
